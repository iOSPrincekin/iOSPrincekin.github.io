使用C语言实现一个词法分析器

Posted on 2020-03-08

写在前面

稍有开发经验的人都知道编译器的重要性，准备实现一个自己的编译器项目。
编译器的结构中，当然是词法分析器最先开始工作的，所以先实现一个语言级别的词法分析器。

词法分析：将输入分解成一个个独立的词法符号，即”单词符号(token)“，简称单词

token一词在不少书中翻译成”记号“，我们认为比较贴切的翻译应当是”单词符号“。它是程序设计语言中
”具有独立含义的最小词法单位“，在这个意义上与自然语言中的”单词“的词义相同。但是，它们又不完全相同，
因为这里的”token“不仅仅包括”词“，还包含标点符号、操作符、分割符等。将它翻译成”单词符号“正是为了
提现这一点。但为了简洁起见，我们使用”单词“一词。

程序语言设计

首先记住，我们的最终目的是实现一门高级计算机语言，就像C、Java那样的高级计算机语言，首先高级计算语言我们理解的最小单位即是”单词符号“，让我们来看下常见的高级计算机语言”单词符号“的种类：

标点符号和运算符、分隔符: (, ), [, ], {, }, :, :=,
., ,, ;, *, /, +, -, =, <>, >, <, >=, <=, &, |.
关键字: array, break, do, else, end, for, function, if, in, let, nil, of, then, to, type, var, while.

标识符: 一个表示符以字母开始，后面跟随零个或者多个字母、下划线、数字，标识符是忽略大小写的，关键字不可当做标识符。

整型:整型变量是由一串0-9的数字组成的。

字符串: A string literal starts and ends with double-quotes. A string can contain printable characters or escapes. Escapes start with a backslash . The allowed escape sequences are:
字符串由”开始和到”结束，一个字符串包含可打印的字符转义字符，允许的转移字符有：

空白符：任何字符串之外的空白符都必须忽视，空白符由空格、制表符、换行符、注释等组成，注释以/*开始，以*/结束,注释是可以嵌套的。

词法分析器的作用就是将输入的一串字符流，识别成一个个”单词符号(token)“

词法分析器的实现：

1.创建一个C语言工程：

这个我创建的是一个简单的xcode工程，里面只包含几个简单的C文件，完全可以跨平台使用

2.创建lex.c文件作为词法分析器的功能实现：

(1).在lex.c文件中实现目标文件的读取和字符流的输出功能；

(2).在读入字符的同时，需要进行字符的判断和理解，这个时候就需要用到正则表达式

例如，对于高级语言中的表示符，我们可以用正则表达式 [a-zA-Z][a-zA-Z0-9_]* 来表示，但是正则表达式只是理论上的匹配，真正做到一个字符判断可模拟的、准执行的需要用到NFA，非确定有限自动机(NFA)是一个需要对从一个状态出发的多条标有相同符号的边进行选择的自动机。

图1：NFA的一个示例图

由于NFA在同一个状态后，接收相同的字符，有不止一条路径可以选择，虽然也可以进行词法分析的实现，但是其的不确定性，导致在判断一个”单词符号token“时，需要记录和回溯(在当前状态判断失败的情况下，回退到上一个成功的状态)，导致效率很低，所以如果能有个”确定的有限自动机“就好了。

(3).将NFA转为DFA

用计算机程序实现确定的有限自动机(DFA)较容易。但是实现NFA则要困难一些，因为太多计算机没有足够好的可以进行”猜测“的硬件
通过一次同时尝试多有可能的路径，可以避免这种猜测。我们用字符串in来模拟图1的NFA。首先从状态1开始。现在，代替猜测应采用哪个ε转换，我们只是说此时NFA可能选择他们中的任何一个。因此，它是状态{1,4,9,14}当中的任何一个，即我们需要计算{1}的ε闭包。显然，不接收输入中的第一个字符，就不可能到达其他状态。
现在要根据字符i进行转换。从状态1可以到达状态2，从状态4可到达状态5，从状态9则无处可去，而从状态14可以到达状态15，由此得到状态集合{2,5,15}。但是，我们还必须计算ε闭包：从状态5有一个ε转换至状态8，从状态8有一个ε转换至状态6。因此这个NFA一定属于状态集合{2,5,6,8,15}。
对于下一个输入字符n，我们从状态6可到达状态7，但状态2、5、8和15都无相应的转换。因此得到状态集合{7},它的ε闭包是{6,7,8}。
现在我们已经到达字符串in的末尾，那么，这个NFA是否已经到达了终态呢?在我们得到的可能状态集合中，状态8是终态，因此in是一个ID单词。

PrincekinKlineFrame K线图库的使用

Posted on 2018-10-23

PrincekinKlineFrame


PrincekinKlineFrame 是使用Swift语言编写的在iOS平台上运行的k线图库，她具有轻量、敏捷、稳定等特点，可为虚拟货币、金融等行业提供专业的k线图信息显示，具有很强的实用性和可扩展性。

使用文档

安装

CocoaPods

1.使用CocoaPods安装，pod ‘PrincekinKlineFrame’
2.引入 ‘import PrincekinKlineFrame’

使用

竖屏
步骤：
1.在你的工程中创建一个类A继承自PKKLineContainerView，PKKLineContainerView是PrincekinKlineFrame竖屏方向上的K线图view；
2.让类A实现PKKLineChangeKlineTypeDelegate代理方法；
3.在类A中创建通过Http请求获取K线图数据，并将获取的K线图数据数据通过从PKKLineContainerView继承来的对象方法initData赋值初始数据；
4.如果使用socket推送更新K线图数据，那么将推送过来的K线图数据通过从PKKLineContainerView继承来的对象方法appendData更新K线图数据；
5.可参考PrincekinKlineFrameDemo
关于
[PrincekinKlineFrameDemo](https://github.com/iOSPrincekin/PrincekinKlineFrame/tree/master/PrincekinKlineFrameDemo)说明：
1.我采用的是OHHTTPStubs模拟网络请求，获取K线图的Http数据，可用于开发过程中的网络调试，如果感兴趣可参考 [OHHTTPStubs](https://github.com/AliSoftware/OHHTTPStubs)
2.为了实现实时推送的效果，我自己写了一个类SocketStob来模拟Socket的推送，在真实的开发开发环境中，推荐使用第三方库 [SocketRocket](https://github.com/facebook/SocketRocket) 来完成iOS的socket连接；
3.虽然有15min、30min、1hour等按钮可以点击，但是我只实现15min的网络数据，在开发过程中，可以更具需要添加网络数据；
